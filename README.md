## Introduction to Machine Learning

Welcome to the **"Introduction to Machine Learning"** repository!  
This project demonstrates foundational machine learning algorithms using Python and popular libraries like Scikit-learn, NumPy, Pandas, and Matplotlib.

---

## 📁 Repository Contents

Jupyter notebook covers the following ML algorithms and concepts:

| Serial No | Title                         | Description |
|-----------|-------------------------------|-------------|
| 1         | **Find-S Algorithm**          | A concept learning algorithm for finding the most specific hypothesis that fits the training data. |
| 2         | **ID3 (Decision Tree)**       | Trained on weather data using the Gini index. Visualized using `plot_tree()`. |
| 3         | **Random Forest Classifier**  | Applied on the breast cancer dataset. High performance with ~96% accuracy. |
| 4         | **Linear Regression**         | Trained on the Iris dataset. Evaluated using MSE and R² score. |
| 5         | **Logistic Regression**       | Performed digit classification using the digits dataset. |
| 6         | **K-Means Clustering**        | Unsupervised clustering on digit data. Evaluated using accuracy and confusion matrix. |
| 7         | **Support Vector Machine (SVM)** | Compared SVM and Logistic Regression. Achieved 98.7% accuracy with SVM. |
| 8         | **Naive Bayes Classifier**    | Binary classification on the Wine dataset. |
| 9         | **SVM for Text Classification** | TF-IDF vectorization + SVM on the 20 Newsgroups dataset. Achieved ~75% accuracy. |
| 10        | **Artificial Neural Network (ANN)** | Implemented using `MLPClassifier`. Visualized the ANN architecture. Compared with K-NN and Weighted K-NN. |
